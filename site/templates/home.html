A C#-like language, taught to a compiler that already exists.

teko has no compiler of its own. Thirty-one hook modules and a runtime teach mc — a small compiler that compiles itself — the constructs its base grammar leaves out: class, interface, trait, generics, delegates, properties, namespaces, dependency injection resolved while compiling and reference counting scoped to the block. mc enters by release, pinned in one file, and nothing in its core changes.

Getting started Reference Internals

  • Taught, never forked

    Not one line of mc changes for teko's sake. The whole language is hook modules in this repository, registered from ordinary source; when mc genuinely cannot express something, the answer is a minimal reproducer sent to that project, never a workaround here.

    31 modules · 0 lines of mc changed

  • It compiles itself

    The taught compiler is one unit, and the proof is a ladder: stock mc builds it, it builds itself, and the third generation comes out byte for byte identical to the second — on five native pairs, each on a machine of that operating system and architecture.

    cmp teko2.o teko3.o → identical

  • Every construct has an oracle

    Forty-five fixtures, each carrying the exit code it must produce, are compiled by the taught compiler and run. What is not taught is refused where it is written, with a short cause; the refusals are a documented surface, not a surprise at run time.

    45 fixtures · no silently wrong result
