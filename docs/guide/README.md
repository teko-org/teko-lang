# The guide

Task-oriented, read in order. Pages land in [D2](../history/design/plano-docs-site.md) of
the docs plan; until then this index is the placeholder the [map](../README.md) links to.
Each page will pair every example with a fixture under [`../../tests/`](../../tests/), so
nothing here describes a construct `mc` cannot yet compile — see
[`../history/design/superficie-v0.1.0.md`](../history/design/superficie-v0.1.0.md) for the
current construct-by-construct inventory.

Planned pages, in reading order: getting started, the project (`teko.toml` vs `mc.toml`),
types (`class`/`struct`), interfaces and traits, generics, delegates and lambdas, arrays,
namespaces, control flow, parameters, dependency injection, memory, and the self-hosting
fixed point.
