# The guide

Task-oriented, read in order. The pages are being written; until then this index is the
placeholder the [map](../README.md) links to, and the
[reference](../reference/README.md) is the complete, construct-by-construct account of
what the taught compiler accepts today. Each page will pair every example with a fixture
under [`../../tests/`](../../tests/), so nothing here describes a construct `mc` cannot
compile.

Planned pages, in reading order: getting started, the project (`teko.toml` vs `mc.toml`),
types (`class`/`struct`), interfaces and traits, generics, delegates and lambdas, arrays,
namespaces, control flow, parameters, dependency injection, memory, and the self-hosting
fixed point.
