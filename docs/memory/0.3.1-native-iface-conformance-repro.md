# native/iface-conformance: reproduced native miscompile of interface signature matching

## Symptom (gen2 native-built, rejects a VALID program the C route accepts)
```
src/io/stream.tks:209:10: 'NullStream' method 'close' does not match interface 'teko::io::Closer's signature
src/build/project.tks:1439883991:21845:
src/checker/escape.tks:1439883991:21845:
...
```
`NullStream.close(self): error | null` and `Closer.close(self): error | null` are IDENTICAL,
so `method_sig_matches` (src/checker/collect.tks:996) must return true. gen2 returns false.

## Garbage-line fingerprint = by-address corruption
Column `21845` = 0x5555 — the top bytes of a PIE/heap pointer (0x5555_5555_xxxx under setarch -R).
A `Position` (line/col) is being read from a slot that actually holds a POINTER: a value used in
the signature-matching path escaped into a region that was reclaimed, so its position/str fields
now read pointer bytes. Same family as 5026006a (bracket_to_root) and 74622f77 (name_escapes_body).

## Reproduction ladder (bootstrap/teko.c is a STALE seed lacking both prior fixes)
- gen0 = cc-link bootstrap/teko.c.
- gen0 --C--> gen1 (fixed codegen, but its OWN native body free-olds copy_relocs_to_current_region_x86
  because stale gen0 emitted tk_slice_push_fo there): gen1 SIGSEGVs native-building gen2.
- gen1 --C--> genB (clean native body: gen1's fixed codegen denies that free-old; verified
  tk_slice_push, not _fo, at copy_relocs).
- genB --native--> gen2 (clean, no crash, peak ~3.3 GB).
- gen2 --native--> gen3: REJECTS stream.tks:209 with the garbage-line fingerprint. <-- THE BUG.

CI reaches this same bug directly from the released seed (which HAS the two prior fixes), so its
gen1==my genB.

## ROOT CAUSE PINNED (native-codegen LOGIC divergence, not corruption/free-old)
`method_sig_matches` compares the resolved return types of `Closer.close` and `NullStream.close`,
both `error | null`. `resolve_type` builds that via `union_normalize_null`, whose first statement is
`mut out: []Type = teko::list::push(teko::list::empty(), Null { })`. The RHS is typed `[]Null`
(bottom-up), so the binding to `[]Type` is an implicit `[]Null` -> `[]Type` element-WIDENING slice
coercion. The C route's `emit_as` (codegen.tks:6640) does this: build the `[]U` value, `malloc`
`len*sizeof(T)`, loop wrapping each `U` into a `T` variant (`cg_wrap_elem_str`). The NATIVE backend's
`lower_value_into_type` (lower.tks:6683) handles a `Variant`/`Reference` bound but for a `Slice` bound
falls to `_ => lower_expr(value)` with NO element widen — so `out` is a `[]Null` slice reinterpreted
as `[]Type`: `out.len` reads fine but `out[i]` reads a 24-byte `Type` wrapper out of a `Null`-sized
buffer -> garbage/dangling. type_eq then mis-compares -> false rejection; the follow-on garbage
positions (0x5555 = PIE pointer bytes) are the mis-sized reads.
Confirmed by probes: DBGUNN crashes reading out[0] right after the binding, before the loop.
81 such widen comprehensions exist in the compiler C (77 -> []Type), source element kinds:
Prim/Str/Char/Byte/Ptr/Uptr/Error/Null (register/fat) and ExprStmt/Binding (boxed aggregate).

## FIX DIRECTION
Add the `[]U`->`[]T` slice-element widen to the native backend's binding coercion
(`lower_value_into_type` Slice arm), mirroring the C `emit_as` malloc+per-element-wrap, using the
uniform 24-byte wrapper (`variant_wrapper_bytes`, payload@`variant_payload_offset`=8).

## MILESTONE: iface-conformance rejection CLEARED
With the []U->[]T widen wired into the fat BINDING path, gen2 no longer rejects
stream.tks:209 (NullStream/Closer). gen2 native-builds gen3 past the interface check.
NEXT native blocker: the SAME widen family at OTHER fat placements (return/assign/arg/
field) — gen3 build still emits a corrupt diagnostic list (empty messages, 0x5555
garbage positions). Wiring the remaining fat placements through lower_fat_expr_into_type
is the continuation.

## FINAL STATE (this PR)
The []U->[]T variant-member slice-widen coercion is now implemented across ALL FIVE fat
placements a value crosses, mirroring the C route's emit_as:
  - binding            (lower_binding_direct)
  - explicit return    (lower_return_fat)
  - struct/class field (store_field_fat_value)
  - call argument      (lower_fat_arg_into_param)
  - function-body tail (lower_body_tail_expr_stmt_fat, vs ctx.ret_type)
plus the tk_slice_variant_widen runtime helper (teko_rt.{c,h}).

RESULTS (native self-build, gen0(bootstrap):gen1(C):genB(C):gen2(native):gen3(native)):
  - The `'NullStream' method 'close' does not match interface 'Closer'` rejection is GONE.
  - The 25 empty-message / 0x5555 garbage-position diagnostics (function-body []Member->[]Type
    tail returns) are GONE.
  - C-route fixpoint BYTE-IDENTICAL (genB.c == genC.c) — the fix is byte-preserving for the C route.
